# CarLog

> A modern digital service book for every vehicle you own.

## Vision

CarLog is a web-first application that helps vehicle owners keep the complete maintenance history of all their vehicles in one place.

The first release focuses on replacing notebooks, paper invoices and scattered photos with a clean, searchable maintenance timeline.

## MVP

- User authentication
- Multiple vehicles per account
- Maintenance timeline
- Maintenance events
- Photo/PDF attachments
- S3 storage
- Maintenance reminders
- Responsive web application

## Tech Stack

- React + TypeScript + Material UI
- AWS Lambda + TypeScript
- DynamoDB
- Amazon S3
- Cognito
- AWS CDK
- pnpm + Turborepo
